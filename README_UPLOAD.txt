UPLOAD THESE FILES TO GITHUB

Repository: https://github.com/murphyskinner357-blip/Murphy-Skinner-Football
Live site target: https://murphyskinner357-blip.github.io/Murphy-Skinner-Football/

1. Open the repository and select Add file > Upload files.
2. Upload every item in this folder, including index.html, robots.txt, sitemap.xml, .nojekyll, the CSV and the submission text.
3. Commit the changes to the main branch.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, then main and /(root), and save.
6. Wait a few minutes and open the live-site target above.
7. After it loads, add the property in Google Search Console, submit sitemap.xml, inspect the home-page URL and request indexing.

The page includes a canonical URL, ProfilePage structured data, descriptive title/metadata, robots.txt and a sitemap. Do not rename index.html.
